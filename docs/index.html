Theoretical Foundations

The Dream-RSI Formulation (Eq. 1)

In high-dimensional discovery spaces, online evaluation is prohibitively expensive. Dream-RSI optimizes the exploration policy π over historical replay 𝒟explore via Pareto AUC quality penalized by sequential reasoning overhead.

Modular Workspace

The 10-Crate System Blueprint

Separation of concerns enforced by Rust compiler boundaries. Hard safety invariants guarantee read-only crawl safety and zero-hallucination replay.

cogni-core
Domain Types
Core data structures: CognitionNode, CognitionTree, DirectionPlan, Score, and DailyProgress models.
cogni-cognition-tree
Topology Analysis
Boundary specification parser, TreeDelta (+N/-M/rK) state tracking, weighted goal_progress & boundary_mastery calculation.
cogni-replay
Offline Simulation
Prefix-only Replay Simulator. Strictly prohibits fabricating unobserved nodes or unauthorized state mutation.
cogni-dreamer
Dreaming Engine
The outer dreaming loop, paper formula (1) simulation scoring, candidate perturbation generator, and winner SQLite sync.
cogni-policy
Exploration Policies
CognitionPolicy trait, BaselineParallelRefining policy implementation, and grid direction planner.
cogni-crawler
Target Adapter
Target SaaS adapters for doc, code, and endpoints. Enforces hard safety default-deny WriteGate.
cogni-llm
Model Transport
OpenAI-compatible client targeting MiniMax-M3 with deterministic zero-cost dry-run fallback.
cogni-store
Persistence
SQLite engine managing daily_progress and policy XML audit tables, with sqlite-vec extension support.
cogni-tui
Visualization
Ratatui terminal dashboard rendering Day Header, Policy Step, Thinking Stream, and Termination Status.
cogni-cli
Entrypoint
Clap CLI exposing dream, tui, show-day, smoke, prompts, and recent-rows commands.

Get Started

Quickstart CLI Commands

Clone the repository and run outer iterations directly using cargo. 

# 1. Clone repository
git clone https://github.com/yekeno/cogni-rsi.git
cd cogni-rsi

# 2. Run full workspace test suite (76 tests)
cargo test --workspace

# 3. Execute 5 outer dreaming iterations
COGNI_ALLOW_WRITE=1 cargo run -p cogni-cli -- dream \
  --db cogni.db \
  --iterations 5 \
  --boundary boundary.yaml

# 4. View persisted records in SQLite
cargo run -p cogni-cli -- recent-rows --db cogni.db --limit 5

# 5. Launch interactive Ratatui TUI dashboard
cargo run -p cogni-cli -- tui --db cogni.db
